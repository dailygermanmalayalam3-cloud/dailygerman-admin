# Daily German Malayalam — Admin CMS

Dedicated administrative portal for managing vocabulary, grammar topics, Goethe exam preparations, and dialogues for the **Daily German Malayalam** platform.

- **Stack**: Next.js 16 (Turbopack), Tailwind CSS v4, Supabase Auth & Postgres.
- **Learner Site**: [https://dailygerman-nu.vercel.app](https://dailygerman-nu.vercel.app)
- **Database**: Supabase (`wivtdopwvgefybojakuo`)
